## 一、配色：每方一个颜色

| 参考 | 配色 | 场景底色 |
|---|---|---|
| A 片 | 主角红橙 / 巨龙紫 / 龙息冰白蓝 | 冷蓝灰云海 |
| B 片雾林 | 己方翠绿 / 对手粉紫 + 橙火 | 冷青灰林地 |
| B 片岩窟 | 对手紫电 / 金色法宝 / 巨蛇毒绿 / 火环橙 | 暗蓝黑岩壁 |
| C 片 | 主角白蓝 / 对手橙红 | 极暗蓝黑夜 |

- 底色压低、去饱和，留给特效和人物衣服跳出来。
- 人物衣服是第二层：白衣放在暗背景上永远读得清（C 片全程）。
- 招牌色贯穿到底，不要中途换色。一场戏颜色最好不超过 3–4 种。

## 二、一团光的结构

从里到外：**白核 → 招牌色 → 暗边或碎屑**。B、C 片所有的光团都是这样，中心几乎是纯白，颜色在外圈。

> 中心白核（white-hot core）过曝发白，外圈才是饱和的翠绿，边缘碎成细小光屑散开。

降温过程也能写（C 片 3.2 秒，轮子吃掉火球）：**白 → 黄 → 橙 → 暗红 → 回到本色**。

> 爆点从白炽退成橙黄，再退成暗红，最后羽状白光恢复本色。

光是长出来的（A 片 10.5–11.3 秒，剑点燃）：手先发亮 → 握拳聚光 → 光从拳心沿剑身抽出来，约 0.25 秒。

> 手心先亮，光从握拳处沿剑身一寸寸抽出去，直到剑尖。

## 三、受光：最值钱的一笔

特效照到的皮肤、衣服、地面都要染上它的颜色，而且**接触前就开始**。

- A 片 46.3 秒：红光先映上袖子和翅膀，白核才出现。
- B 片 63–66 秒：女子整张脸和袖子被绿光打亮，一半绿一半粉，瞳孔不发光。
- B 片 175.3 秒：黑暗里只有手臂和半张脸是绿的。
- B 片 87–90 秒：大招时皮肤、衣服、树木全部染粉，这是大招的信号。
- C 片 23.5 秒：地面被羽轮打成一片亮白。

> 翠绿光先打亮她的指节和袖口，下巴边缘染上一层绿；粉紫盾光映在她另一侧的肩头。她的脸只有自然光，眼睛是正常人眼，不发光。

**受光别直接打在正脸上（实测）。** 参考片里脸被染色很好看，但在 Seedance 里，法术光一照亮正脸，尤其「从下往上照亮脸」，眼睛就发蓝光、红光。受光写在手、袖子、衣襟、肩头和下巴边上；特写用四分之三侧脸，法术光留在画面外。近景里确实要半边脸映色时，同一段写明「眼睛是正常的深棕色人眼，不发光，没有蓝光、红光」。

**前景和背光的反差：** B 片 181.4 秒是全片最强的构图之一：前景大黑盾是纯剪影，后面绿白光爆亮，人脸一半被绿光打亮。写法：

> 前景一面巨大的黑铁圆盾是纯黑剪影，边缘被背后爆亮的绿光吃掉一圈；他的肩头和下巴边缘被绿光勾出一道亮边，眼睛是正常人眼。

## 四、爆炸怎么分层

**标准四层**（B 片 65.7–66.5 秒）：

1. 只闪一瞬，白核（约 0.1 秒）
2. 招牌色晶片和碎光向外飞（约 0.1 秒）
3. 彩色烟团膨胀，吃掉大半画面（约 0.3 秒）
4. 切远景，碎光四散，烟团慢慢收拢（约 0.3 秒）

**大爆炸接力**（B 片 116.5–124 秒）：同一个爆炸换 5 个机位，每层一个颜色：白 → 紫 → 橙 → 粉，每刀 0.2–1.3 秒，然后一个 2.8 秒的安静镜头，人飞出去，躺在地上。

**实物碎裂**（B 片 267.2–268.5 秒）：碎金片像落叶慢飘，尘烟从下往上缓盖。

> 一瞬闪白后，粉紫晶片和翠绿碎光从盾心向四周炸开；紫色烟团迅速膨胀，吞掉大半画面；切远景，碎片减速，一片片慢慢飘落。

## 五、护盾与法阵

**圆盾**（B 片 47–53 秒）：半透明，两层，外圈蕾丝状花纹、内圈水波纹。命中点白亮，每中一下荡开一圈同心波纹。飞剑钉在盾上还在颤。

> 半透明紫色圆形法盾（translucent energy shield），外圈是镂空的蕾丝状花纹，内圈是细密水波纹，透过盾面看得见后面的树林。

**裂纹**（A 片 48–48.5 秒）：沿球面从撞击点往外爬，发光，不是一下子全碎。

**半球护罩**（B 片 154.7–157 秒）：光束打上去被劈开，**顺着球面绕流**，罩内的人依然清楚。破的时候变成碎晶和白爆。

> 毒绿光柱打在半球护罩上被劈开，光流顺着球面向两侧绕过去；罩内三人身影清楚。

**法阵**（B 片 138.9 秒、197–203 秒、215–218 秒、229.5 秒）：

- 悬空圆盘，半透明，符纹多层，侧面看得出厚度，不要写成贴在画面上的图标。
- 上中下分工最壮观：**顶上一层金色法阵，中间白雷从阵下劈落，地面火海**（B 片 215–218 秒）。
- 法阵也能当计时器：岩壁上的符文圈一点点变大，被镜头推到满屏（B 片 196.9–203.4 秒）。

> 上方悬着一面金色多层法阵，缓缓转动，符纹发光；白色雷电从阵底劈向地面；地面是翻滚的火海。

## 六、光束与飞行物

- **飞行物要有实心头和长尾**：C 片的橙红发光方块、红圈都拖着长长的尾巴（C 片 1.5 秒、13.2 秒）。
- **冲镜**：物体从远处由小变大，冲到贴镜（B 片 7.6 秒沙兽、264.5 秒金砖；C 片 2.8 秒羽轮）。
- **斜贯全屏**：光束从一角斜到对角，比水平更有力（B 片 155–157 秒、178–180 秒）。
- **穿前后景**：光束从背景穿过树林打到前景（B 片 76 秒）；光带横穿人物身前（C 片 1.5 秒）。写清楚谁在光前、谁在光后。
- **地面火路**：一条火或岩浆从远处沿地面直奔镜头（B 片 104 秒、259.9 秒）。
- **横向镜头光晕**（anamorphic lens flare）：爆炸前一瞬的预告（B 片 223.2 秒）。
- **火环**：环飞过去套住目标，再收紧（B 片 133 秒、214 秒；A 片 71 秒的巨型火弧像星球边缘铺满下半屏）。

三段片里最有分量的特效都有实物：

| 实物 | 依据 | 写法要点 |
|---|---|---|
| 金砖 | B 片 221–281 秒 | 方块结构，表面刻发光纹路，贴镜时纹路铺满屏；能在空中折叠拼合 |
| 青叶飞剑 | B 片 6–10 秒、47–53 秒 | 一片片在身边出现，拖绿尾，钉住会颤 |
| 黑盾 | B 片 181–184 秒 | 纯黑剪影，不发光 |
| 羽轮 | C 片全程 | 中心是看得见的机械轮，外面裹羽状白光 |
| 油纸伞 | B 片 107–109 秒 | 橙色伞面在紫焰里撞色 |

## 八、皮下透光

法力由内往外透，比外面裹一层光高级得多：

- A 片：黑羽翅膀的羽根里透熔岩红橙，龙的鳞缝和眼睛透紫。
- B 片 135.6 秒、190 秒：蛇皮下浮出橙色裂纹。

> 黑色羽翼的羽根内部透出熔岩般的红橙光，羽尖有细小火星飘落；鳞片缝隙透出暗紫光。

## 九、细丝与光针

大片光效配极细线条，粗细一对比才高级。

- C 片 44–46 秒：指尖牵出极细的蓝白光丝，操纵画外的法器，地面留下划痕光线。
- C 片 26 秒：黑场中细光线一根根向外放射。
- B 片 140 秒：一排细长光针。

## 十、水墨羽状光（C 片风格）

这是 C 片的招牌，真人实拍配白蓝羽状光。

- 形态：羽毛状，边缘飞白（dry-brush），旋转成环，中间能透过去看到东西。
- 夜景极暗，蓝黑底，白衣高亮，整体接近黑白。
- 烟是蓝白的气旋，绕着人转（C 片 13.8–14.5 秒）。
- 地面白化：全白地面加黑色碎屑，俯拍，再慢慢抬起露出地平线（C 片 27–29 秒）。

> 羽状白光绕着机械轮旋转成环，羽毛边缘像毛笔飞白一样散开；白光把脚下的石板打亮；画面其余部分压到几乎全黑。

## 十一、残影

## 十四、特效设定图怎么准备（实测）

**哪些要出图：**

- 招牌法术，形状模型猜不准的：冰锥阵、火轮、凤凰燃翼、风旋。
- 要在好几条里长得一样的。没有图，每条生成的形状都不一样，接不上。
- 能直接在视频里生成的不出图：护体火用火焰图就够；化身后的带翼人形用化身图加人物图直接生成。

**图要怎样：**

- **背景干净，图里不放人**，连比大小的小人影也不要；大小靠「占满大半个画面」这类构图写法。
- **参考图的背景色会进视频**，写「不取图片背景」也挡不住。实测：深灰底的冰墙图把整片天带成了深灰。占满画面的大面积特效最容易带背景，这类图要么背景接近本场的天空，要么不接图、改用文字写。
- **图里的朝向会被照搬**，写「不取朝向」没用。出图时就按戏里的方向出，或者翻过来再上传；不然时间轴每一处都写死方向。
- **一整块的阵图进视频像静止贴图。** 接这种图时，时间轴写「上百根前后错开、各自在飞」。
- **图的颜色不对**（比如偏黄），同时出两版图，提示词只差那张图和描述它的那一句，各跑一版对比。

**在【素材引用】里怎么写：** 每张特效图一句，写清是谁的什么法术、颜色和形态、虚还是实、归谁所有，只取什么、不取什么：

> (图片6) 是崔珏的灵力，半透明的冰蓝白光雾裹着发光霜点，是虚的，归崔珏所有；只取形态、颜色和质感，不取图片背景。

**出图分工：** MJ 提示词交给 `mj-cinematic-prompts`。用户会自己把特效图、人物图、场景图喂给 MJ 当参考，提示词只写构图（画什么、几个、在画面哪里、朝哪边）。需要用户出图时明说：哪张、为什么现有的不够、建议喂哪几张参考图、存成什么名字、不出图的退路。用户试过用 MJ 出大景静帧，控不住构图，以后再提这个办法前先问。

## 十五、冰、灵力和风（实测）

**同一个人的法术分三层虚实，写清楚，模型才不会混：**

| 层 | 写法 | 不要 |
|---|---|---|
| 灵力（手上、身上） | 半透明的冰蓝白光雾，裹着发光霜点，是虚的 | 丝带、流（会变成发光水带）；手凝成冰 |
| 放出去的冰（冰刃、冰锥） | 写实：薄处透明、厚处淡蓝，有乳白冰芯、冻住的气泡、表面白霜，形状不规整，冰本身不发光 | 冰里流着灵光（整块发光像贴图） |
| 法术凝成的防御（冰墙） | 虚一点：轻、透、里面流着淡淡灵光、边缘散成冷雾 | 圆冰盾（像镜片）；实冰巨浪、冰川崖壁（太实，不像法术） |

**冰锥阵：** 上百根冰锥前后错开、各自在飞，每根拖一道白霜尾迹；斜着砸（「从画面左上方往右下方」，每处写死）；整体移动，长短形状不变。催动要有动作链：灵力卷成旋涡 → 掌心聚光 → 在身后冻成阵 → 举起双臂 → 一砸射出。

**风旋：** 「灵力化成的一股横着往前钻的白色旋风，后面宽、前面收成尖，里面卷着细雪、少量小冰晶和发光霜点，中段绕着两圈被推开的气浪」，再加一句「是风，不是冰块，他的手是空的」。

**冻霜：** 一层白霜从掌下飞快往外长，顺着对方的护腕、袖子、臂甲一路往上冻，霜花一片片长开；冻到肩甲或领口就停住，「脖子和脸上始终没有霜」。

**几版都没做好、后来放弃的：** 冰刺花、冰刺笼、冰笼（会画成蛋形笼）。用户想要包围感时，先提别的招。

## 十六、火（实测）

**火的样子：** 「深赤红到熔岩橙的翻卷火焰，边缘散成黑烟和火星」。要像火，不像羽毛。

**挡招的火：**

- 单手格挡时小臂裹一层火，挡完还有余火。
- 护体火壳：「隔着半透明火壳看得清他本人，皮肤和衣服保持原本颜色」；【保持一致】写「他本人没有着火」。出招 → 挡住 → 余火放在同一条、同一个不切的镜头里。

**第一次全身爆发**（3D 近身逼火，粗剪用了 6 刀）：

> 他胸口先亮起一点白光，只闪一瞬；紧接着涅槃火从他全身同时往外炸开，不到半秒涨成一团比他高好几倍的火球：中心发白，外圈是深赤红到熔岩橙，边缘翻出黑烟和火星。他臂上的霜一瞬间化成白汽喷开。火光先一步扑到对手身上，把他的纱袍和袖子一下映成赤红；对手被火球正面冲开。他在火里看得清，他本人没有着火。

**火星：** 写小（米粒、黄豆大小），不然会画成乒乓球大的红球。变化分步写：又快又直飞去、突然停住、变亮、起热浪、裂开、窜出火舌、炸开。轨迹写清往哪飞：要放到对方脚下，就往下飞。

**火轮：** 「真实火焰翻卷成环，有明暗、火舌、细黑烟和热浪，不是光滑发亮的圆环」；写成光环会像动漫里的甜甜圈。起手给手部特写：掌前火星连成火线，卷成一只比肩还宽的火轮，手腕一抖甩出去。一群火轮写「十来只，有的从正面直直切过来，有的划着弧线从上下两边绕过去」。

**火球、火弧：** 火球「拖着长长的火尾，呼啸着射向他」；弯月火弧「横扫过来」。

**冰火相撞：** 白汽是冰火之间最好的介质。

- 相碰处：「冰火相碰，嘶嘶冒白汽」。
- 压灭：「冰蓝光雾裹住火球，火球在他身前一臂远被压灭，炸成一大团白汽」。白汽还没散，就从白汽里卷出下一招。
- 大招互相抵消：正面撞上 → 全屏闪白 → 白汽和冰晶占满画面 → 一方从白汽里冲出来。
- 碎墙：「冰和火一起炸开，火里带着碎冰，最后散成黑烟」。只写冰碎，就只有冰块没有火。

## 十七、化身（实测）

实测场高潮：强者被大招逼到亮底牌，从火球里化成凤凰，再变回背带燃烧双翼的人形，一掌结束。

**流程（拆成三条生成，外加一条特写素材）：**

1. 冰锥阵砸下，他往上冲、裹成火球硬接，冰锥实实砸在火球前面碎裂。
2. 火球炸开，火浪中心展开双翼，化成全身是火的凤凰，和对方的大招一样大。
3. 凤凰同时扇火、吐火；中间穿插对手咬牙加力的近景。
4. 两边正面撞上、互相抵消。
5. 凤凰从白汽里冲向对手，冲的途中在火里变回带燃烧双翼的人形。

**写法要点：**

- 「凤凰就是他本人，画面里没有人形的他」。
- 写参照物定大小：「和整座冰锥阵一样大，对手在它们面前只是一个小点」。
- 火要多：「头、颈、身子、双翼和长尾都裹在火里；两只翅膀从翼根到翼尖每一根羽毛都在烧，火比翅膀本身还厚」。用户第一轮的意见是「变身太普通，火焰非常少，碰撞的速度非常慢」。
- 眼睛：「深金色的鸟眼，不发光，只反着火光」。
- 接图：化身形态图，加一张燃翼特效图，写「只取翅膀上火焰的多少、分布和形态，不取图中的姿势和朝向」。带翼人形不出图，用化身图加人物图。
- 只变一次。高潮要多出素材：再出一条只拍特写的（燃烧的翅膀、头颈、身下仰拍扇火），剪辑时穿插。

## 十八、高空云海（实测）

- **只用一张场景图**，前景什么都没有，只有云海和远处的小山尖。带前景山石松树的图一接，人就像站在地上。
- **天气写死**：「晴天蓝天，太阳在画面右上方」，场景图取光线。
- **人永远悬在半空**：近景背景只有天空和云；全景写「两人离下面的云海很高，脚下隔着很深的空气」，机位和人差不多高。全景最容易像站在云面上。
- **白衣服衬在蓝天前**，不要衬在白云前。
- **介质**：冲过薄云冲出一个圆洞；俯冲掠过云顶，在云海上划出一道长沟，云屑往两边翻；风压把下面的云压出凹槽；火浪从云里炸出；对撞把云卷成旋涡。
- **【保持一致】**写「两人始终悬在半空，背景只有蓝天和云海，没有地面、山石和树」。
