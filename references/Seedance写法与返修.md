# Seedance 2.5 写法与返修

规则跟「上古影视工作流」插件保持一致，这样提示词可以直接上玄上画布。平台数字以当前入口为准；本机装了插件时，最新规则在插件的 `shared/Seedance平台.md` 和 `shared/素材引用写法.md`。

## 一、平台要点

- 每条 4–30 秒。玄上画布默认 21:9、多模态参考、样片。
- 素材：图片、视频、音频分别从 1 开始编号；人物 1–8 个时最稳定。
- 参考视频总长不超过 30 秒；单段最短按 4 秒算。
- 玄上画布第一版不支持参考音频，人物音色和环境声写成文字。
- 真人脸素材按入口不同，能否通过要看当前入口的实际反馈。
- 血和人身上着火可能让生成判成黑屏失败；直接拿画布上已生成的视频做编辑可能被以版权为由拒绝。写法和绕法见 `实测经验.md` 第九节。

## 二、符号（写错会出问题）

| 符号 | 在 Seedance 里的意思 | 怎么写 |
|---|---|---|
| 半角 `()` | 音乐 | 只用于素材引用 (图片N)、(视频N)；术语括注一律用全角（） |
| `【】` | 字幕 | 只用作五个区块的标题 |
| `{}` | 台词 | 角色台词（语气）：{台词原文}；台词后不追加语气和动作 |
| `<>` | 音效 | 需要时用，通常用文字描述就够 |

## 三、素材引用

- 正文每一处都带括号和编号：(图片3)。不写「图片3」「(图片7)、8」「(图片1)至(图片3)」。
- 编号和接入的素材一一对应，每个素材都要被引用。
- 还没有素材时用 `@角色名` 占位，代码块外注明；上画布前必须换成 (图片N)。
- 每条视频各自编号，不要把上一条的编号搬过来。

## 四、任务类型和用词

默认是参考生视频，第一句不写任务类型。全文不要出现：修改、替换、增加、删除、延长、延续、续写（改用「保持」「承接」），否则可能被判成编辑或延长任务。

首尾帧、关键帧、视频编辑、视频延长的写法不同：关键帧第一句写「以(图片1)、(图片2)、(图片3)的顺序作为关键帧」；延长写明向前或向后延长哪个视频；要在已有视频上改，交给 `video-local-edit`。

### 首帧单镜头（实测）

用户给了一张首帧图（自己出的静帧，或从粗剪里截的），要从这一帧开始一镜到底跑一个镜头，常用来救一个大远景或特效镜头。实测场的 S28、S34、S29、S54 都这样跑通，时长 4 秒。

- 【素材引用】第一行写：「(图片1) 是这个镜头的第一帧，也是整个镜头唯一的机位和景别」，再用一句话说清首帧里谁在哪、各是什么东西。
- 【生成目标】写死：「整条视频只有一个镜头：从(图片1)这一帧开始，一镜到底跑满 N 秒，固定机位，不切镜头，不换景别，不推近，不摇镜头」。
- 【时间轴】只写一段（例如 `0-4s：`），开头再写一次「构图和景别从头到尾都和(图片1)一样，摄影机不动」。只写这个景别里看得见的动作：远处小人只写身体姿势和衣袖，不写脸、眼神、头发细节。
- 一写摇镜、推近、人物脸部细节，模型就会自己切出仰拍和人物中景（实测 S34 第一版）。
- 要飞的东西写「整体移动，长短形状不变，原来的位置空出蓝天」，不写「拉长」（实测 S34 第二版被越拉越长）。
- 跑检查脚本时加 `--single-shot`，它会改查「有没有切镜」，不再提示切镜偏少。

## 五、时间轴细则

- 时间戳只用整数秒，时间段首尾相接，从 0 开始，末段写实际秒数。
- 时间段不等于切镜。要切镜写「切到……」，不切写「同镜连续」。
- 每个镜头写：景别、焦距及透视景深结果、机位运镜、动作、特效和反馈、结束时状态。
- 普通镜头选一个精确焦距，不写范围。打戏用超广角时写出画面效果。
- 帧率、升格倍率、机身、分辨率不写进提示词。慢动作写成「能看清什么」。
- 动作先概括，只把有记忆点的写细；不重复描写同一个动作。
- 左右一律写「画面左/右」；要用人物自己的左右时写「她自己的左手」。
- 中文为主；运镜、布光、材质、VFX 术语可用「中文（English keyword）」。

## 六、篇幅

只算【时间轴】，标点不计。打戏算最复杂戏：15 秒以内不超过 4000 字，16–30 秒不超过 6000 字。这是上限，不是目标。

## 七、声音

- 默认不要音乐。音乐类同义词列全（音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音），【生成目标】和【保持一致】各写一次。打戏的特效音尤其容易被做成音乐。
- 避免提到水泡声、回音、啸叫一类的声音描述，容易出杂音。
- 用户要配乐或字幕时，按用户说的改。

## 八、保持一致

```
人物身份、人数、服装、道具归属、空间方向、光源方向保持一致。
人物为正常人眼，不发光。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音。
```

- 不超过 5 行，不要和时间轴打架：有残影、瞬移就不要写「无瞬移」；有爆炸闪白就不要写「光线稳定」；被甩飞的衣服破损要写在时间轴。
- 法术场面容易诱发眼睛发光，这行尽量保留。剧情要求眼睛发光时才删。实测里特写多的条，这行写成「所有特写里眼睛都是正常的深棕色，没有蓝光、红光」更稳。
- 实测有用的另外两类约束，按需各写一行：
  - **场地**：「两人始终悬在半空，离下面的云海很高；背景只有蓝天和云海，没有地面、山石和树」。
  - **法术边界**：谁的手不凝成实体、火只在谁身外、霜只在哪里、脸上没有霜、方向始终朝哪边。模型最爱越界的就是这几处。

## 九、空话换成看得见的

| 不要写 | 写成 |
|---|---|
| 炫酷、华丽的法术 | 从哪来、什么颜色、什么形状、照亮了谁 |
| 强大的灵力爆发 | 地面裂开，落叶向外炸开一圈，她的袖子被吹直 |
| 动作凌厉、充满力量 | 前脚抓地，肩先转，手臂后到，衣袖慢半拍 |
| 震撼的大爆炸 | 一瞬闪白，紫烟膨胀吞掉大半画面，碎片慢慢飘落 |
| 眼神一冷 | 目光从盾心移到他脸上，嘴唇绷紧 |

## 十、返修表

下面这些问题是打戏最常见的，改法来自三段片的做法，大多还没有在 Seedance 上逐条验证。**先查 `实测经验.md`**，那里是实际跑出来的问题和改法；两边冲突时以实测为准。

| 看到的问题 | 通常原因 | 改法 |
|---|---|---|
| 特效像贴上去的 | 没有介质，没有受光 | 加雾、尘、落叶；写光照亮了谁；皮肤袖子先染色 |
| 全程很亮，没有冲击力 | 没有明暗节奏 | 底色压低一档；每次大闪之后写一段暗镜或脸 |
| 人被光吞掉，看不见 | 特效太大太亮，人没分离 | 人物放到光的前面或侧面，写边缘被照亮；白衣放暗背景；爆炸后切到人清楚的镜头 |
| 谁打谁看不懂 | 没有阵营色，方向不清 | 每方一个颜色；用正侧面；加一个俯拍 |
| 动作软，没力量 | 没有前摇和定姿 | 蓄力写长，出手写短；加定姿；身体停了衣发再动 |
| 法术像游戏技能图标 | 法阵平贴、干净 | 写半透明、有厚度、多层、缓慢转动，并有光落到地面 |
| 切得太碎、跳 | 一条里刀数过多，或者没有过刀方法 | 减少快切，改用动作中切、遮挡、闪白过刀；保留 1 个长镜；拆成两条 |
| 刀数比设计少很多 | 时间段不足 1 秒被合并（实测） | 每个时间段至少 1 秒，快切写在一段里 |
| 全程一个景别 | 没写切镜 | 按「定位置 → 看人 → 出手 → 看飞行 → 命中 → 看脸 → 看结果」排 |
| 瞬移像跳帧 | 只写了「瞬移」 | 用拍型 6，起点、终点留残影，中间空镜，光线先到 |
| 爆炸一团糊 | 没有分层 | 按闪白、白核、彩烟、碎片慢飘分开写 |
| 打完戛然而止 | 没写余波 | 加碎片慢飘、尘云、俯拍、地上留下的东西 |
| 飞剑跑到手里，或者多了一把 | 剑的身份没写清 | 写清这一段剑在脚下、手里还是离手；切换写交接动作 |
| 袖子乱飘 | 没有写力的方向 | 写袖子跟身体同向且慢半拍，身体停了才落下 |
| 巨兽和人比例忽大忽小 | 没有参照 | 每个镜头写参照物：头有多大、人站在哪、岩壁多高 |
| 脸崩、脸被光吃掉 | 特写和强光同时出现，或者动作太大 | 脸的特写减少动作，光放在侧面；糊的动作不放脸上 |
| 眼睛发光（实测） | 法术光照亮正脸，尤其从下往上照；冷光照脸 | 特写用四分之三侧脸，法术光留在画面外，脸上只写自然光；同一段写「眼睛是正常的深棕色人眼，不发光」 |
| 不该笑的时候在笑（实测） | 写了轻蔑、挑眉 | 写「嘴唇闭着，嘴角平直」「神情平静，眼神一沉」 |
| 特效音变成音乐 | 没写全音乐禁词 | 开头结尾各写一次完整的禁词 |
| 出现字幕 | 用了【】或台词后跟描述 | 检查符号；台词后不追加内容 |
| 动作像软绵绵的位移（未实测） | 只写了「极快」「瞬间」 | 把速度落到画面上：音爆白雾、地面被蹬裂、后坐力推着人滑出深槽（`特效光效.md` 第六节） |
| 法宝、兵器一下子就出现，像贴图（未实测） | 成形过程没拆 | 拆成 4–6 步，每步写材质（`特效光效.md` 第二节） |
| 冲击波没力量、范围看不出（未实测） | 环境同时动，或者没动 | 写近处先动、远处晚半拍；加一刀摄影机被推开（`运镜与衔接.md` 第六节） |
| 连招漏招、顺序乱、每下都一样（未实测） | 只写了「连续进攻」 | 连招起名 + 每击单独一句、打不同部位 + 最后复述顺序（`武打与施法动作.md` 第十节） |
| 模型老按默认方式做（未实测） | 只说了要什么，没排除它爱做的 | 加一句「不是 A，而是 B」（第十一节） |


## 十一、几种好用的句式（未实测）

来自一组公开 AI 打斗作品的镜头字幕，下面是反复出现的写法。没在实测场跑过。

**每个镜头的骨架：** 「景别或焦段（可带变化箭头）：机位运镜，主体做了什么，环境被它改成什么样。」本 skill 的时间轴格式本来就是这样，那组作品的特点是后半句几乎只写物理结果，不写形容词。

| 句式 | 例子 | 用在哪 |
|---|---|---|
| **不是 A，而是 B** | 「飞剑不是直线飞向他，而是贴着水面绕到他身后」「竹叶不是垂直落下，而是在敌群里面不停变向」 | 模型有默认做法时，先排除它，再说要的 |
| **给次数** | 「连出三剑」「两波」「三次打击」「四道弧线」 | 连招、连射、连爆；不给次数，模型常少做 |
| **短句、句号断拍** | 「他站着不动。下一瞬间。人没了。」 | 瞬移、连击这类要一拍一拍切的段落 |
| **点名「同时有」** | 「这一枪同时有：枪身银白拖影、流水一样的光、细密的蓝白电丝」 | 一下里最想要的两三个效果，放一句点名，不要分散到几句 |
| **用视线落点讲动机** | 「老人的目光没看他的脸，直接落在他腰间的镜子上」 | 文戏转武戏、交代谁想要什么 |

**秒数：** 那组作品里直接写过「遮满屏约 0.2 秒」「全屏爆白持续 1.5 秒」。本 skill 默认还是按 `SKILL.md` 的翻译表写成看得见的说法（「只闪一瞬」「顶住约一秒」），没实测前不改默认。
