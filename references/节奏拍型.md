一条视频选一个主拍型。下面的秒数都是从原片逐帧量出来的，用来设计节奏；写进提示词时按 `SKILL.md`「把参考片的数据翻译成提示词」换成看得见的说法。

## 一、实测节奏数据

程序读完了三段片的每一帧，切镜和亮度都是算出来的。切镜检测有少量误差：压黑转场偶尔被算成 0.1 秒的短镜（B 片较多）。

| | A 片 | B 片 | C 片 |
|---|---|---|---|
| 时长 / 帧率 | 105 秒 / 24 | 284 秒 / 30 | 57 秒 / 30 |
| 镜头数 | 85 | 232 | 46 |
| 每秒几刀 | 0.81 | 0.82 | 0.81 |
| 平均 / 中位镜长 | 1.24 / 0.96 秒 | 1.23 / 1.00 秒 | 1.24 / 0.97 秒 |
| 最长镜头 | 6.0 秒 | 7.2 秒 | 6.0 秒 |
| 全屏闪亮次数 | 17 | 38 | 20 |
| 闪亮中位间隔 | 4.8 秒 | 4.7 秒 | 1.4 秒（扎堆出现） |
| 画面中位亮度（0–255） | 98 | 75 | 73 |

合计 363 个镜头的长度分布：

| 镜长 | 个数 | 占比 | 用来干什么 |
|---|---|---|---|
| 不足 0.5 秒 | 69 | 19% | 冲撞、出手路径、遮屏、闪屏 |
| 0.5–1 秒 | 105 | 29% | 单个动作、反应 |
| 1–2 秒 | 133 | 37% | 一招的完整过程 |
| 2–3 秒 | 40 | 11% | 蓄力、顶住、脸 |
| 3 秒以上 | 16 | 4% | 比例、法阵、绕飞一镜 |

**怎么用：** 15 秒约 12 刀，其中约 2–3 刀是快切，至少 1 个 2 秒以上的长镜。2 秒以上的镜头只占 16% 的个数，却占 37% 的时长。C 片和 B 片的基础画面偏暗（中位亮度 73–75），特效才跳得出来；白天戏或云海戏（A 片）基础亮度高，靠颜色对比。

## 三、十八个拍型详解

### 1 蓄放中余（最常用）

依据：B 片 262.8–268.5 秒（推掌祭砖）。

| 阶段 | 实测 | 画面 |
|---|---|---|
| 蓄 | 约 0.6–0.8 秒 | 爪形手后张，身体后蓄，掌心一粒小光 |
| 放 | 约 0.2 秒，连切 3 个极短镜 | 转身、推出、掌心光糊，每刀更近 |
| 飞 | 约 0.3–0.5 秒 | 切全身，背景放射状模糊，法宝由小变大冲镜 |
| 中 | 约 0.1 秒 | 一瞬闪白或白核 |
| 爆 | 约 0.5 秒 | 招牌色烟尘涌开 |
| 余 | 1–3 秒 | 碎片慢飘，尘云缓盖，反应脸或大远景 |

### 2 顶裂炸（防御被破）

依据：A 片 45.9–49.0 秒；B 片 65.1–66.5 秒。

横挥到位约 0.3 秒 → 红光先映亮衣袖 → 白核 → **顶住约 1.1 秒，画面几乎不动** → 切侧面近景见护盾全貌 → 裂纹沿球面爬约 0.7 秒 → 炸只有 0.1 秒 → 碎屑白雾吃满画面约 0.3 秒 → 切大远景，人从雾里冲出。

要点：顶的时候别动，靠头发后压和身体小抖；越静，裂开时越响。

### 3 对撞

依据：A 片 72.8–74.3 秒；B 片 42.2 秒、259.2 秒。

火弧匀速变大约 0.3 秒 → 一帧跳满屏 → 火星最密约 0.15 秒 → 余烬约 0.5 秒（夹几颗贴近镜头的虚焦大光斑）→ 留约 0.6 秒干净画面。

要点：写清谁赢。A 片里火弧碎了，冰息继续往前，观众立刻明白局势。机位用正侧面，两人分左右，中点相撞（B 片 42.2 秒、50.9 秒），方向最清楚。

### 4 茧爆（大招起手）

依据：A 片 74.3–77.3 秒；B 片 87.1–90.5 秒。

翻滚约 0.8 秒 → 翅膀或袖子合拢成茧，只见背，内里透红约 0.25 秒 → **弹开只用 0.1 秒左右（全糊）** → 张开定住，从暗红慢慢烧成橙黄约 0.6 秒 → 火星喷出 → 镜头持续后拉约 1 秒，人从占画面 6 成高缩到 1 成，火星拉成放射线。

节奏口诀：静、弹开、再静着烧、放。B 片的版本：双手托球 → 举起 → 紫电沿地面爬向四周树木，皮肤和衣服全部染粉。

### 5 终结

依据：A 片 91.8–102.5 秒；B 片 238.1–284 秒。

低机位正面对称，几乎不动约 1.1 秒 → 背后一瞬亮起圆日，翅膀染橙 → 兵器落到面前，一根竖直光柱穿过人物中线，镜头推 → 光柱扩到全屏（人脸残影还透着）→ **硬切俯拍结果**（云层被烧出火环，一个小黑点坠落）→ 砸地，裂缝和水柱慢半拍炸开 → 烟散亮相约 2.5 秒 → 钩子（对手的眼睛又亮了，或者碎石下露出蛇头）。

### 6 闪现残影

依据：B 片 38.7–40.5 秒。

定姿（一手剑指竖在脸旁）→ 招牌色光掠过全身，发尾染色 → 转身，身体变半透明 → 人走了，**残影留在原地淡出** → 近乎空镜约 0.35 秒 → 飞叶和细光线先到 → 人从远处落到中景 → 冲到近景糊掉 → 人离开，残影留在中景。

要点：起点、终点各留残影，中间给空镜。这是解决「瞬移像跳帧」的直接办法。

### 7 旋袖定姿（身法躲避）

依据：C 片 4.5–6.8 秒、9.6–11.4 秒。

面朝镜头定一下 → 身体基本不动，双袖慢半拍左右飘（0.5 秒）→ 整体旋成一团白约 0.2 秒 → 低身弓步定姿，一手前指，袖子在前景拖成长弧（0.5 秒）→ 切远景。同时火流星带长尾从前景和背景多个方向穿过。

节奏口诀：旋、定、旋、定。定的时候才露脸。

### 8 绕身法器

依据：C 片 18.5 秒、23.5–25.6 秒；B 片 6.3 秒（飞剑在身边一片片出现）。

贴地超广角一镜约 2 秒：人低身当轴，两件法器绕身转，近大远小，转到镜头前时贴镜遮挡。法器是主光源，把地面打亮。人只小幅俯身移位，运动主要交给法器。接一个正俯拍，地面石板被气流甩出同心圆。

### 9 法阵齐射

依据：B 片 138.9–151.3 秒。

人物手前开阵（圆盘半透明，从侧面看得出厚度）→ 一排细长光针从画面一角斜射到对角 → 命中，白色碎方片、紫电、橙火三色叠加 → 大远景见小人小兽和水面倒影 → 手托光球推向镜头 → 俯拍敌人被一圈光针钉住，光线向外放射 → 压黑。

### 10 巨物揭示

依据：B 片 220–265 秒。

小物件在掌中发光 → 单指托举，物件悬在脸旁，表面纹路清楚 → 物件上升，目光追着走 → 仰头 → **镜头沿岩壁上摇，巨物慢慢压入画面** → 仰头特写 → 反打：从巨物角度俯拍人，张臂，掌心发光 → 砸下。

要点：别一开始就给全貌。靠人的视线和上摇把观众带上去。

### 11 蓄满被杀

依据：B 片 87.1–93.6 秒，后接 96.5 秒。

大招蓄到最满，紫电满屏 → 突然切暗林空镜约 0.5 秒 → 切回时血先出现 → 插入特写（剑、血、白衣）→ 裙摆甩成大圆，身体后仰，约 0.75 秒只有极慢后仰和手臂上抬，光团渐灭 → 切极远景的小小身影 → 地上剩一颗发光的珠子。

要点：最亮之后接最静。特效灭掉本身就是结果。

### 12 贴身绕飞

依据：A 片 21.6–23.4 秒、85.9 秒（6 秒一镜）。

沿巨兽身侧跟拍，人很小，绕一圈，兵器划过鳞片亮一下，亮点越来越密 → 火星散开 → 白爆 → 放射火星满屏 → 人体贴镜遮屏 → 切走。

### 13 穿插旁观者

依据：A 片 53.1–60 秒；B 片 155.9 秒、175.3 秒、271.1 秒。

插在高潮前后。枝叶后偷看的半张脸，或者抱头的手和袖子，或者抬头的脸。只有皮肤和袖子被特效染色，人几乎不动，1–4 秒。

### 14 缠斗换位（实测）

依据：实测场追逐B 第二版（12 秒，粗剪用了两版共 10 刀）。

| 秒 | 距离层 | 画面 |
|---|---|---|
| 0–2 | 远 → 撞 | 大远景，两人同时瞬移，在天空正中撞出白核，镜头急推冲向白核 |
| 2–3 | 远 | 三刀快切，在天上不同位置连闪连撞 |
| 3–6 | 近 | 穿越机一镜不切，贴身缠斗，边打边俯冲掠过云顶，双方都在进攻 |
| 6–7 | 近 | 中景手持，扣住手腕把他甩出去 |
| 7–8 | 中 | 全景跟拍，被甩的人翻一圈稳住，同时回敬一团火球 |
| 8–10 | 中 | 中景，压灭火球成白汽，从白汽里卷出下一招 |
| 10–12 | 远 | 急拉成大远景，瞬移躲开，扑空，两人隔空对峙 |

要点：每两三秒换一次距离层（远 → 近 → 中 → 远），每一层换一种打法；每次换层都有一个动作把两人推开或拉近。不环绕的镜头写死左右。

### 15 逼出底牌（实测）

依据：实测场 3D 近身逼火（10 秒，粗剪用了 6 刀）。

弱者借上一招掩护贴身冲到强者面前 → 一掌按住强者格挡的手臂 → **接触点特写**：霜从掌下往上冻，把他臂上的火压灭 → 越过弱者肩头，强者低头看被冻住的手臂，眉头第一次一紧 → 弱者四分之三侧脸特写，咬牙，双掌推到底 → 强者胸口一点白光只闪一瞬，全身爆发，不到半秒涨成比他高好几倍的火球 → 全景，弱者被热浪冲飞翻滚，白汽团留在原地。

要点：先压住（静、越来越暗）→ 一闪 → 炸。强者第一次认真一定给脸；弱者那一下要真的有威胁，强者的强才衬得出来。

### 16 成形挥出看规模（未实测）

依据：公开 AI 打斗作品（凝剑、冰原雷电），未实测。

| 阶段 | 景别 | 画面 |
|---|---|---|
| 成形 | 特写，连续 4–5 刀 | 光核 → 丝带收拢 → 液态流动 → 外形包出厚度 → 尖端光点（`特效光效.md` 第二节） |
| 发力 | 中景 → 特写 | 握住，手腕、肘、重心、腰胯依次动；或后脚蹬实、身体压低 |
| 挥出 | 广角迎面 | 剑气、光柱在透视下迅速变大，边缘几乎擦过镜头，吞没画面 |
| 看规模 | 正俯拍或超远景 | 攻击一路切开云层、烟层、地面，路径清楚；人很小 |
| 余 | 中景 | 后坐力推人滑退、脚下留痕，或能量收回成一小团 |

要点：前半段慢、细、近，后半段快、大、远。成形的每一步都写材质，不要一句带过。

### 17 快慢反差收尾（未实测）

依据：公开 AI 打斗作品（竹林斩兽、红莲剑客），未实测。

高速厮杀（全景、超远景交替）→ **突然拉到远景**，人变小，四周倒满敌人 → 镜头正面高速倒退跟拍，他慢慢往前走，不回头，右手缓缓握拳 → 最后一下在他背后爆发（环形切割波扩散、敌阵崩溃），或者碎片像雨一样落下。

要点：人越小、周围倒下的越多，反而越显强；慢慢走和前面的高速形成反差，像「战斗已经结束，他懒得回头确认」。最后那一下不让主角回头看，压迫感最强。

### 18 出场（未实测）

依据：公开 AI 作品里的角色出场段落，未实测。

交代环境（甩镜追拍从高空坠落，长焦仰拍砸进殿宇）→ 怎么入场（一张咬牙抬眼的脸；过肩看对手压满半边画面）→ **多机位局部特写，先不露全貌**（胸、肩臂、腰腿、背、头的侧后方轮流切）→ 完整亮相（低机位仰拍，冲击波炸开）→ 冲出去。

要点：公式是「交代环境 → 怎么入场 → 局部特写留悬念 → 最后完整亮相」。很多打戏一上来就打，或者人平平地走出来，少了这一段铺垫。

## 四、怎么排成一条视频

**15 秒骨架（打一招、挡住、破防）：**

| 时间 | 内容 |
|---|---|
| 0–2 秒 | 比例或站位：谁在左、谁在右，小光点起 |
| 2–4 秒 | 蓄 + 连切出手 |
| 4–7 秒 | 飞行、命中、顶住 |
| 7–8 秒 | 给脸（受光） |
| 8–10 秒 | 裂、炸，闪白过刀 |
| 10–13 秒 | 受击飞出、落地 |
| 13–15 秒 | 俯拍看结果，余烬飘 |

**30 秒骨架：** 用两个拍型接起来，中间夹一段穿插旁观者或压黑。

**一整场戏（参考 B 片每场的结构）：** 小道具或小光点开场 → 试探 → 升级 → 反应脸 → 大招 → 大远景加烟尘 → 钩子。每一场都这么走，观众会有预期，打起来也不累。

**拆条：** 切点首选动作接刃：上一条停在动作做到一半，下一条接着做完（实测 6 个接缝都接上，见 `运镜与衔接.md` 第七节）。其次才是闪白、压黑或人体遮屏，下一条开头接同一个亮度或遮挡状态。连着的一串动作（出招 → 被挡 → 余波）不拆开。在【时间轴】结束时写清人物位置、朝向、动作阶段和烟尘状态。实测场一条多用 12 秒，补镜 4 秒。

## 五、实测出片数据

实测场用户自己粗剪的 V5 版，对比三段参考片：

| | 三段参考片合计 | 实测场粗剪 V5 |
|---|---|---|
| 时长 / 镜头数 | 445 秒 / 363 刀 | 139 秒 / 99 刀 |
| 平均 / 中位镜长 | 1.23 / 1.00 秒 | 1.41 / 1.20 秒 |
| 不足 1 秒 | 48% | 27% |
| 1–2 秒 | 37% | 51% |
| 2 秒以上 | 16% | 22% |

**说明了什么：**

- 粗剪比参考片慢一点，主要是不足 1 秒的快切少。快切在生成里难出，想要就按「一个时间段里连续三刀快切」写。
- 约 75 条生成里，有 37 条被剪进了粗剪。一条 12 秒的生成常能剪出 4–7 刀，写得好的一条，连同换了一张特效图的另一版，合计剪出 10 刀。设计时一条 12 秒按 6–8 个时间段写。
- 99 刀里 10 刀被用户加速 1.2–2 倍，2 刀倒放。生成出来的动作偏慢，提示词要写得更快。
- 粗剪是用户从很多批素材里挑着拼的（37 个来源），所以每条都要能单独剪出几刀好用的；一条里一两段没出来不要紧，补跑那一段就行。

## 六、一整场的模板（实测）

实测场 V5 粗剪的结构，可以当作「两人打一场、强者一直让着」的模板。强弱曲线见 `武打与施法动作.md` 第十二节。

| 段 | 粗剪时间 | 内容 | 拍型 |
|---|---|---|---|
| 亮相 | 0–7 秒 | 弱者从下面冲上来，强者垂眼俯视，两人对峙 | — |
