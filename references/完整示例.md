# 完整示例

四条成品，展示同一套规律怎么用到不同的戏。

- 示例一到三：人物和法宝都是举例，用 `@` 占位，上玄上画布前要换成 (图片N)。没有在 Seedance 上生成验证过，第一次用时建议先出样片看效果。
- 示例四：实测场真跑过的一条，原样照录，后面附生成结果和粗剪里用了哪几段。

不要照抄词句。要学的是结构：谁先亮、谁先动、哪里闪、闪完切什么。

## 示例一：雾林破盾（15 秒，白天，拍型 1 + 2）

```
【素材引用】
人物（按首次出场顺序）：
@沈砚 是白衣剑修；只取面部、发型和本场服装，不取图片背景
@苏晚 是紫衣女修；只取面部、发型和本场服装，不取图片背景
场景：
@雾林空地 是雾气弥漫的林间空地；只取空间结构和陈设，不取图中人物和光线
道具：
@青叶飞剑 是七柄翠绿细长飞剑，归沈砚所有；只取形制、材质和尺寸
声音（无参考音频）：飞剑破空声，钉入法盾的脆响，裂纹的细碎咔嚓声，碎晶落地声，落叶被气流卷动的沙沙声。

【生成目标】
横屏真人电影写实，古装仙侠打斗。沈砚在雾林空地用七柄飞剑连射，打碎苏晚的紫色法盾，把她震飞落地。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音；只保留动作声和环境声。

【光影设计】
- 主光方位：画面右上方的阴天散射光穿过树冠
- 光质：环境是柔光（soft light），术法光是硬光（hard light）
- 光比：林地压暗，人物和术法明显亮于背景
- 动机光源：沈砚掌心和飞剑的翠绿灵光，苏晚法盾的粉紫灵光
- 色调：冷青灰底色，翠绿和粉紫对撞
- 主体与背景分离：白衣和紫衣衬在暗林和雾气前，术法光勾亮靠近它的一侧轮廓

【时间轴】
0-2s：全景，20mm 超广角（ultra wide angle），贴地低机位，近处落叶占画面下缘，地面线条向远处急剧汇聚，机身微微倾斜。沈砚在画面左侧低身弓步定姿，一只手剑指竖在脸旁，另一只手向后平伸，指尖亮起一粒翠绿小光点，把周围的雾气染出一小团绿色。苏晚在画面右侧远处抬手，身前张开半透明紫色圆形法盾（translucent energy shield），外圈是镂空的蕾丝状花纹，内圈是细密水波纹，透过盾面看得见后面的树林。固定机位。结束时：沈砚保持定姿，法盾立在苏晚身前。
2-4s：切到近景，100mm，背景虚化。沈砚五指成爪向后张开，上身后蓄，掌心光点变亮，翠绿光先打亮他的指节和袖口，头发被带得前飘。紧接连续三刀快切，每刀不足半秒，沿推掌路径越切越近：第一刀肩膀先转；第二刀手臂推出，衣袖糊成一片；第三刀掌心翠绿光拖尾冲向镜头，背景拉成放射状（radial motion blur）。结束时：七柄青叶飞剑从掌前成扇形飞出，冲出画面右侧。
4-7s：切到正侧面中景，35mm，两人分列画面左右，法盾在画面中间偏右。飞剑拖着细长绿尾依次钉在盾心，每中一柄，盾心闪一下白核（white-hot core），盾面荡开一圈同心波纹，落叶被气流向外推开一圈；飞剑钉住不落，还在颤动。苏晚弓步顶在盾后，前脚抓地，头发和袖子被风压向后拉直，身体只有细微抖动，画面几乎不动地顶住约一秒。结束时：七柄飞剑钉满盾心，颤动未停。
7-8s：切到特写，135mm，苏晚的四分之三侧脸在画面右侧，背景虚化成绿紫色块。盾外的翠绿光打亮她的袖口和下巴边缘，粉紫盾光映在她肩头；她的脸只有林间的自然光，眼睛是正常人眼，不发光。她的目光从盾心移开，看向沈砚的方向，嘴唇绷紧。结束时：一道裂纹的白光从她脸上掠过。
8-10s：切回正侧面中景，35mm。发光裂纹从盾心沿盾面一路爬向边缘。只闪一瞬，全屏闪白（white flash）；粉紫晶片和翠绿碎光从盾心向四周炸开，紫色烟团迅速膨胀，吞掉大半个画面。结束时：紫烟占满画面，只有边缘露出一点树林。
10-13s：切到中景跟拍，50mm 手持，紫烟翻滚。苏晚从紫烟里倒飞出来，身体向画面右侧翻转，裙摆甩成大圆，头发和袖子都比身体慢半拍。她后背落地滑行，铲开一道落叶，手撑地停住，头发散乱地抬起头。紫气从她衣摆上慢慢散开。结束时：她半撑在地上，面向画面左侧。
13-15s：切到正俯拍，28mm，高空。地面落叶被气浪推出一个圆形空地，中央散着发光碎晶；沈砚小小地立在画面左侧，苏晚小小地撑在画面右侧，七柄飞剑缓缓飞回他身边。碎片和余烬慢慢飘落，紫烟和雾气合拢。结束时：两人隔着圆形空地对峙，飞剑悬在沈砚身侧。

【保持一致】
人物身份、人数、服装、道具归属、空间方向、光源方向保持一致。
人物为正常人眼，不发光。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音。
```

为什么这样写：翠绿对粉紫，一眼分清两方（规律 5）；光点先亮，手再动（规律 3、4）；顶住时画面静，裂开才响（拍型 2）；闪完留脸不够，又给了俯拍看结果（规律 7、11）。

## 示例二：岩窟祭印（15 秒，夜，拍型 10 + 1）

```
【素材引用】
人物（按首次出场顺序）：
@陆行舟 是白衣修士；只取面部、发型和本场服装，不取图片背景
其他主体：
@墨蛟 是覆盖黑青鳞甲的巨蛇，抬头时高过人物十倍；只取形态与颜色
场景：
@地底岩窟 是有水潭的巨大岩窟；只取空间结构和陈设，不取图中人物和光线
道具：
@镇岳金印 是方块叠成的金色法印，表面刻满纹路，归陆行舟所有；只取形制、材质和尺寸
声音（无参考音频）：碎石滚落声，巨物压下的低沉闷响，金属撞击岩石的轰鸣，尘土落地声。

【生成目标】
横屏真人电影写实，古装仙侠打斗。陆行舟在岩窟祭出掌心大的金印，金印升空变成宫殿般大，砸中巨蛇。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音；只保留动作声和环境声。

【光影设计】
- 主光方位：开始时只有掌中金印的光，照亮他的手指和下巴边缘；后段金色主光从画面上方压下来
- 光质：金印是硬光（hard light），岩窟环境是极弱的冷色柔光（soft light）
- 光比：岩壁暗到接近黑，只有被金光照到的部分显出质感
- 动机光源：金印自发光，巨蛇口中的毒绿光
- 色调：暗蓝黑底色，金色对毒绿
- 主体与背景分离：白衣衬在黑色岩壁前，金光勾亮肩膀和发丝

【时间轴】
0-2s：近景，85mm，背景是虚化的暗蓝岩壁。陆行舟单手托着一枚掌心大的金印，金印内部透光，把他的手指内侧和下巴染成金色，表面的刻纹清楚。他并拢两指，指尖一粒金色火星。金印离开手掌，慢慢悬到他脸旁。结束时：金印悬在画面左侧他脸旁，他的目光落在它上面。
2-4s：同镜连续。金印开始上升，他的目光追着它走，慢慢仰起头，金光从他的下巴和衣襟上一点点退下去，眼睛是正常人眼，不发光。结束时：他完全仰头，金印飞出画面上方。
4-6s：切到全景，24mm，低机位。镜头沿着岩壁向上摇，碎石和灰尘从高处簌簌落下，金光先把岩壁上部染亮。一块方块叠成的巨大金印慢慢压入画面上方，比整面岩壁还宽，表面每一道刻纹都在发光，横向镜头光晕（anamorphic lens flare）一闪而过。结束时：金印占满画面上半部分，还在继续下压。
6-8s：切到高角度反打，28mm，从金印边缘向下俯拍。陆行舟小小地悬在岩壁前，双臂平伸，两只掌心各亮一团金光，衣摆缓缓下垂，头发被下压的气流向下吹。他脚下远处，巨蛇抬起头，张开的口中亮起毒绿光，水潭面被风压得发皱。结束时：巨蛇喷出一道毒绿光柱，斜向上打向金印。
8-9s：连续三刀快切，每刀不足半秒。第一刀，特写，100mm，他咬牙，手掌下按。第二刀，中景，35mm，毒绿光柱打在金印底面炸成白核，顺着金印边缘绕流。第三刀，特写，50mm，金印刻纹贴着镜头滑过，铺满整个画面。结束时：画面全是发光的金色刻纹。
9-11s：切到全景，28mm，正侧面。金印砸中巨蛇，只闪一瞬，全屏闪白；白光退成金黄，再退成橙红，尘浪从金印底部向两侧猛涌，碎石和金色碎片向外飞。结束时：尘浪吞掉画面下半部分。
11-13s：切到中景，35mm，巨蛇的身体在前景弯成一道弧，压在金印下面。碎金片一片片看得清，像落叶一样慢慢飘落，尘烟从下往上缓缓盖过来。金光渐渐暗下去。结束时：尘烟盖住大半个金印。
13-15s：切到大远景，24mm，高角度。岩窟全貌，小小的陆行舟悬在画面左侧，金印半埋在尘烟里，还透着余光，水潭映出一点金色。尘慢慢落下。结束时：画面右下角碎石间，一只蛇眼亮起暗绿色的光。

【保持一致】
人物身份、人数、服装、道具归属、空间方向、光源方向保持一致。
人物为正常人眼，不发光。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音。
```

为什么这样写：先小后大，靠视线和上摇把观众带上去（拍型 10）；实物刻纹比光球有分量（规律 8）；结尾留钩子（拍型 5）。

## 示例三：夜宫羽轮（15 秒，夜，水墨风，拍型 7 + 8）

```
【素材引用】
人物（按首次出场顺序）：
@白衣男 是白衣修士，操纵两只羽轮；只取面部、发型和本场服装，不取图片背景
@红衣客 是对手，放出拖红尾的火符；只取面部、发型和本场服装，不取图片背景
场景：
@夜宫广场 是月夜的石板宫殿广场；只取空间结构和陈设，不取图中人物和光线
道具：
@羽轮 是两只中心为机械轮、外裹羽状白光的法器，归白衣男所有；只取形制、材质和尺寸
声音（无参考音频）：衣袖破风声，火符飞过的呼呼声，爆裂声，石板被风压震动的闷响。

【生成目标】
横屏真人电影写实，带水墨质感的古装仙侠打斗。白衣男在夜宫广场甩袖躲开连射的火符，以双轮反击，把红衣客击飞。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音；只保留动作声和环境声。

【光影设计】
- 主光方位：羽轮和火符是主要光源，天上只有极弱的冷月光
- 光质：术法是硬光（hard light），月光是柔光（soft light）
- 光比：背景压到几乎全黑，白衣高亮，反差极大
- 动机光源：羽轮白蓝光，火符橙红光，远处檐下几点小灯
- 色调：接近黑白的蓝黑底色，只有白蓝和橙红两种颜色
- 主体与背景分离：白衣衬在黑色夜空前，石板被羽轮打亮

【时间轴】
0-2s：大远景，24mm，低机位，正面对称。夜宫广场几乎全黑，远处檐下几点小灯。白衣男小小地站在画面中央，红衣客在画面远端，手中亮起一粒橙红光点。结束时：橙红光点裂成七张火符，向白衣男飞来。
2-5s：切到中景，50mm，低机位，背景全黑。白衣男面朝镜头，身体基本不动，双袖慢半拍地向一边飘开，又甩回来，袖口像水一样改变形状。拖着长红尾的火符从他身前和身后同时穿过，橙光依次打亮他的白衣和袖口。他猛地旋身，整个人和袖子转成一团白色，随即低身弓步定住，一只手前指，另一只袖子在前景拖成一道长弧，像一笔水墨。结束时：身体已经停住，发丝还横飞了一下才落回，一张火符擦着袖子飞过。
5-6s：连续两刀快切，每刀不足半秒。第一刀，特写，85mm，他指尖牵出极细的蓝白光丝。第二刀，中景，35mm，袖子甩向镜头，把整个画面遮成一片糊白。结束时：画面全白。
6-9s：同样的糊白中切到全景，16mm 超广角，贴地低机位，地砖线条向远处急剧汇聚，地平线倾斜。白衣男低身当轴，两只羽轮绕身旋转，羽毛边缘像毛笔飞白一样散开，转到近处时显得巨大，转到身后时变小；羽轮把石板打成一片亮白。一只羽轮转到镜头前，贴镜遮住画面。结束时：羽轮的羽毛遮满画面。
9-11s：切到正俯拍，28mm，高空。白衣男站在中央，两只羽轮绕他旋转，石板上的积雪被气流甩出一圈圈同心圆。他向前一指，一只羽轮离开轨道，朝画面上方飞去，在地面划出一道发光的直线。结束时：羽轮飞出画面上方。
11-13s：切到全景，28mm，红衣客的方向。羽轮迎面撞上他挡起的火符，只闪一瞬，全屏闪白；白光退成橙黄，再退成暗红，羽状白光恢复本色。他被推着向镜头飞来，身边留下蓝白气旋，蜷身，从镜头边掠过，衣摆遮了一下画面。结束时：他飞出画面。
13-15s：切到大远景，24mm，低机位，正面对称。红衣客在雪地上滑出一道长痕，小小地停在宫殿前。白衣男远远站着，一只羽轮缓缓飞回身侧。雪和余烬慢慢飘落。结束时：两人一远一近，宫殿压在画面上半部分。

【保持一致】
人物身份、人数、服装、道具归属、空间方向、光源方向保持一致。
人物为正常人眼，不发光。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音。
```

为什么这样写：基础亮度压到极低，只留两种颜色；用袖子和羽轮连续贴镜过刀（规律 10）；身法靠「旋、定」和衣发余势（规律 9）。

## 示例四：空中瞬移缠斗（12 秒，白天，拍型 14，实测）

实测场的「追逐B_瞬移缠斗_v2」，原样照录。接 8 张图：人物 4 张（崔珏脸、崔珏服装、帝鸿脸、帝鸿服装）、场景 1 张、特效 3 张（崔珏灵力、崔珏霜风旋、帝鸿涅槃火）。参数：Seedance 2.5、多模态参考、样片、21:9、12 秒。

(图片5) 是烟海阁上空的高空云海，晴天，蓝天，太阳在画面右上方；取空间结构、云层形态和光线。
特效：

**生成结果**（12 秒，289 帧）。用户看过说「这批素材挺好」，粗剪 V5 里用了这一条和换了霜风旋图的另一版，共 10 刀：

| 设计的段落 | 粗剪里用到的样子 |
|---|---|
| 0–3 秒 同时瞬移、连闪连撞 | 冰雾和红影在云上对冲，镜头推到两人脸对脸、冰火相撞；红影和冰团在天上一撞，冰团落进云海 |
| 3–6 秒 穿越机缠斗 | 没有一直穿梭：出来是掌对掌特写、越过崔珏肩头对掌，镜头再甩到正上方俯拍。另一版这段出了俯拍云洞里扭在一起的两人，用户倒放着用 |
| 6–8 秒 扣腕甩出、回敬火球 | 用的是帝鸿翻身踢开、在空中甩出一颗火球；扣腕甩出在粗剪里看不出来 |
| 8–10 秒 压灭火球、卷出霜风旋 | 崔珏张开双臂，火球打来，他甩袖化开 |
| 10–12 秒 瞬移躲开、对峙 | 大远景，两人在云上隔开对峙，都在画面里 |

为什么这样写：每两三秒换一次距离层，远撞、近缠、中距离法术、再拉远（拍型 14）；双方都在进攻，每一下防守里都带反击（底线 3）；穿越机、急推、急拉、手持各用一次（底线 11）；不环绕的镜头写死左右，大远景写「两人身形都看得清」；【保持一致】把法术的边界写死：风不凝成冰、火不上身、脸上没有霜。

从结果看：一镜到底的长镜里写的四五组动作，模型只做出了一部分，换成了它自己的切法；短的段落大多照写的出。扣腕甩出单独占了 1 秒，粗剪里还是看不出来，要观众看清的接触动作可以再给一个特写段。
