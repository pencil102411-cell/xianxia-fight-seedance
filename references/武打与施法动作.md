# 武打与施法动作

三段片的打斗以法术对轰为主，拳脚贴身很少。人的动作主要是**出招的姿势、躲闪的身法和被打的反应**。力量感主要靠定姿、衣发余势和受光，不靠招式多。

实测场补上了参考片缺的部分：空中近身缠斗、强弱不对等的打法、缩地成寸、表情和带伤，见第十一到十五节。用户要的是攻防一体、边打边换位置，不是站着对轰。

标「胡」的写法来自抖音博主胡小绿的 Seedance 2.5 打斗作品（贴身兵刃戏比参考片多），没在实测场跑过。

## 一、四条动作原则

1. **招式停在定姿上。** 动作糊的时候观众看不清，定住那一下才看得懂。旋、定、旋、定。
2. **身体先停，衣发后停。** 头发、袖子、裙摆比身体慢半拍。身体停了之后，发丝再横飞 0.3 秒（B 片 217.1–217.4 秒）。
3. **前摇比出手长。** 蓄力约 0.6–0.8 秒，出手约 0.2 秒。慢的衬托快的。
4. **脸和手保持能看清，其他可以糊。** 手臂、袖子大面积运动模糊没关系（C 片），定姿的瞬间脸和掌心要清楚。

## 二、定姿库

都写成看得见的姿势，写清画面左右和朝向。

| 定姿 | 样子 | 依据 |
|---|---|---|
| 拉弓式 | 一手高举过头，一手胸前掌心亮，身体扭转 | B 片 260.7–261.5 秒 |
| 剑指式 | 一手剑指竖在脸旁，一手向后平伸，转头看目标 | B 片 38.7 秒 |
| 低身弓步 | 重心压低，前腿弓后腿蹬，一手前指，一手后扬，袖子拖在身后 | C 片 10.8–11.3 秒 |
| 张臂悬浮 | 双臂平伸，掌心向外发光，身体略后仰，脚离地 | B 片 54.6 秒、232 秒、251 秒；C 片 42.8 秒 |
| 举兵过头 | 双手举剑过头，低机位，正面对称 | A 片 92–93 秒 |
| 抱球式 | 双手胸前虚抱一团光 | B 片 1.3 秒、87 秒、255 秒 |
| 托举式 | 单手托光或物件在肩旁 | B 片 79.8 秒、221.5 秒 |
| 背身高举 | 背对镜头，单手高举，头发甩开 | B 片 217 秒 |

## 三、施法手势库

手的特写要写手指形状和光的位置。**手一定是光的来源**，光从掌心、指尖、指缝出来。

| 手势 | 写法 | 依据 |
|---|---|---|
| 剑指 | 食指中指并拢，其余收起，竖在脸前，指尖一粒小光 | B 片 38.7 秒、221.5 秒 |
| 爪形后张 | 五指张开成爪，手腕后折，蓄力 | B 片 262.8 秒 |
| 推掌 | 手掌推向镜头，光透指缝，脸在后面 | B 片 26.6 秒、62.7 秒 |
| 掌心托光 | 手掌向上，掌上悬一团光，光照亮手指内侧 | B 片 79.8 秒、143.3 秒 |
| 双手抱球 | 十指相对，光在中间越来越亮 | B 片 87 秒、255 秒 |
| 划圆 | 手臂划圆，轨迹带光，把法阵划出来 | C 片 45 秒 |
| 牵丝 | 指尖牵出极细光丝，手指微动，法器在远处跟着动 | C 片 44 秒 |
| 抓地 | 手按住或抓住地面，白气从指缝溢出 | C 片 27 秒 |
| 手部舞动 | 双手缓慢交替划动，袖子跟着飘，掌心慢慢聚光 | B 片 133.5–135.5 秒 |
| 单手掐诀 | 单手掐诀，指尖弹出一粒火星（代替打响指） | 实测场粗剪 S28 |
| 翻手 | 手掌往上一翻，掌心燃起一簇火或涌出一团光雾 | 实测场 2F 起手亮招 |
| 手势对应环境（胡） | 每换一次手诀，就有一片区域的东西跟着变：左手一挥，左边的竹叶横扫过去；右手一压，空中的竹叶垂直砸下 | 胡·竹林老修士 |

**手势要和环境响应一一对应**（胡·竹林老修士）：操控大量东西（竹叶、飞剑群、水、沙）时，写清「哪个手势 → 哪一片东西 → 怎么变」，观众才看得出是他在控制，而不是东西自己在飞。一段里写两三组就够。

## 四、推掌：一招拆开写

依据：B 片 262.8–264.3 秒。这是全片最完整的一招，其他招式可以套这个结构。

1. 特写前摇：爪形手后张，身体后蓄，头发前飘（约 0.6 秒）。
2. 转身：肩先走，手还在后面（约 0.2 秒）。
3. 推出：连切，手臂和袖子糊掉，掌心光拖尾（每刀不足半秒）。
4. 切全身：身体前探，背景放射模糊，掌心一团金光（约 0.2 秒）。
5. 星芒爆开，法宝飞出。

> 特写，他爪形五指向后张开，上身后蓄，头发被带得前飘。连续三刀快切，每刀不足半秒：第一刀肩膀先转；第二刀手臂推出，衣袖糊成一片；第三刀掌心金光拖尾冲向镜头。切全身，他前探，背景拉成放射线。

**大招也有反作用力**（胡·冰原雷电）：出手前后脚先蹬实、身体压低；放完被后坐力推着往后滑，脚下留痕。这一下让「这一招有多重」看得见。

> 她后脚蹬实冰面，身体压低；光柱射出的同时，后坐力推着她在冰面上往后滑出一大段，脚跟犁出两道深槽，冰屑和白雾从槽里翻起来。

**握兵发力写到关节**（胡·凝剑）：握住兵器后，按顺序写手腕下沉、肘部放松、重心微调、腰胯带着上身转，再出手。

## 五、甩袖身法

依据：C 片 4.5–6.8 秒、9.6–11.4 秒。C 片真人部分的质感几乎全靠袖子。

- 长袖甩开像一个白色扇面，带明显运动模糊。
- 身体转圈时袖子成圆盘，转定了袖子才落下来。
- 躲闪：后仰 + 甩袖，让飞来的光带从身前穿过（C 片 1.5–2.5 秒）。
- 袖子可以直接盖住镜头过刀（C 片 26 秒）。

> 他身体基本不动，双袖慢半拍地向左飘开，又向右甩回，袖口像水一样改变形状；火流星从他身前和身后同时穿过。

写法注意：袖子的运动要跟身体的力同向，并且「慢半拍」；否则容易变成乱飘。

## 六、顶住

依据：A 片 46.5–47.6 秒；B 片 181.4–183.5 秒；B 片 15.8–17 秒（弓步顶盾）。

顶住要有力，但不能动得多：

- 弓步，前脚掌抓地，身体前压。
- 只有头发、袖子被风压向后吹；身体小幅抖动。
- 脸一半被光照亮，咬紧牙关；光打在盾上不打在脸上。
- 镜头几乎不动。

> 她弓步顶在盾后，前脚抓地，头发和袖子被风压向后拉直，身体只有细微抖动，画面几乎不动地顶住约一秒。

## 七、受击

被打的人要有明确的力向，和打过来的方向一致。

| 受击类型 | 画面 | 依据 |
|---|---|---|
| 被冲飞 | 白爆中人被推向镜头，身边留蓝白气旋，腾空蜷身，冲过镜头 | C 片 13.5–15 秒 |
| 被甩飞翻滚 | 跟拍，人在空中翻转，四肢和衣摆甩开，紫气裹身 | B 片 67–71 秒 |
| 贴地滑行 | 雪地上滑出长痕，小小地停在宫殿前 | C 片 45.9–49.7 秒 |
| 被雷劈中 | 绿雷从天而降，地面炸开灰尘圈，俯拍人躺在圈中央 | B 片 72.6–75 秒 |
| 跌地特写 | 手撑地，头发散乱，抬头 | B 片 71.3–72.6 秒 |
| 穿胸 | 血先出现，插入特写，裙摆甩成大圆，极慢后仰，手臂上抬，光灭 | B 片 91.2–92.5 秒 |
| 巨兽被烧 | 皮下透橙光，头裹火，火星飞，甩头 | B 片 135.6 秒、188 秒 |
| 巨兽被压 | 砖压住身体，身子弯成弧，头最后从碎石里露出来 | B 片 267.2 秒、281 秒 |
| 被无形力拉起 | 俯拍躺地，被拉到悬空，张臂后仰，冰从脚向上爬 | C 片 50–52 秒 |

避免只写「被击飞」。写清：打中哪里、往哪飞、怎么翻、落在哪、落地后地面有什么变化。

## 八、飞行

A 片全程在空中，几个做法：

- 翅膀张开亮相（A 片 31 秒）：从云里升起，展臂约 2.6 秒。
- 桶滚（barrel roll）（A 片 62.8 秒）：翅膀卷成圆环冲镜。
- 翻滚规避（A 片 50.2 秒）：靠云的倾斜表现滚转。
- 冲刺时贴脸（A 片 83.8 秒）：头发和衣服全部向后。
- 下落（A 片 94 秒）：俯拍云洞里的小黑点。

C 片的悬空：身体微微后仰，四肢放松，衣摆缓缓下垂，像被托着，不是吊着（C 片 12.5–13.1 秒、42.8 秒）。

## 九、反应脸

- 近景或特写，1–2 秒，基本不动。
- 只变一两样：目光移动、呼吸、嘴微张、皱眉。
- 特效的颜色染在衣襟、下巴边和背景上，这样哪怕只切一张脸，也和打斗连在一起（B 片 175.3 秒、180.2 秒）。
- 眼睛保持正常。「瞳孔不发光」要写进提示词，强情绪容易诱发瞳孔发光。
- 实测：法术光直接照亮正脸，眼睛就容易发光。特写最稳的写法是四分之三侧脸，法术光留在画面外、照不到脸，脸上只写自然光，再写「眼睛是正常的深棕色人眼，不发光，没有蓝光、红光」。

## 十、贴身兵刃近战（参考片很少）

三段片几乎都是隔空斗法，贴身拼刀只有零星几处：A 片 45.9 秒的横剑、A 片 21.6 秒的剑划鳞片、B 片 43–45 秒的剑指咽喉。所以这部分不是拆片学来的硬数据。需要拼刀时，先照搬同样的节奏原则（蓄长放短、定姿、衣发余势、闪完留白），再补三点：

- **写清接触点**：刀砍在剑身哪一段、火星往哪溅、手腕怎么被震。
- **每个回合只看一组攻防**：多人围攻时，一刀只看一个对手，靠切镜轮流交代，不让三个人同时做复杂动作。
- **对手要有效**：对手的进攻要逼出主角的动作，不当站桩。群战里没在进攻的敌人也不能僵住，要一直在动：后退、围拢、举兵防（胡·3A 游戏风）。

胡小绿的作品里贴身兵刃戏多，下面几条从他那里补（未实测）：

- **一击分三段：起势 → 攻防有因果 → 打完有惯性**（胡·三国杀文案）。
  - 起势：先转体、蹬地、抬手，力量从哪来看得见；
  - 因果：对方按来招的方向格挡、闪避或反击，不是各打各的，上一招的结果决定下一招；
  - 惯性：打中或落空后，重心偏一下、顿一下、再调整，才进下一招。不写这段，人就像没有重量一样连续「甩技能」。
- **每一击打不同方向、不同部位**（胡·赵云、红莲剑客）。真人打斗不会只瞄一个位置。不写「砍向他」，写「挑开兵器 / 压低身子削膝 / 回身刺胸」。
- **连招先起名、再分击写、最后复述顺序**（胡·赵云骑战）。三连招这样写最不容易漏招或打乱：先起名，接着第一击、第二击、第三击各写一句，最后补一句「三击顺序是挑、削、刺，每一击都留下光痕」。等于说两遍。
- **近身格挡写一串具体动词**（胡·济公）。一句里写四五个动作，比「激烈格斗」有用得多：「拂袖、拨挡、截腕、旋身卸力、贴身闪开」。

> 切到中景，50mm，正面快速后撤跟拍。她从他头顶翻过，落地连出三剑，每一剑打不同位置：第一剑，挑开锤柄；第二剑，压低身子削他膝甲；第三剑，转腰回身刺向护心镜。三剑顺序是挑、削、刺，每一剑都在空中留下冰蓝光痕。

更细的近战写法在插件 `horizontal-cinematic-prompt-agent-v2` 的 `modules/动作戏.md`（动力链、受击、连招），本机装了插件时可以读。

## 十一、空中近身缠斗（实测）

依据：实测场的追逐 A、B、C 第二版，2E 环绕近战，3D 近身逼火。这几条在用户的粗剪里被用得最多。

**四条原则：**

1. **每一下防守里都带反击。** 挡和打是同一个动作的两半，不是你一下我一下。
2. **腿也出招。** 抬膝、扫腿、踢开，不只是对掌。
3. **双方手上都带法术光效**（掌心光雾、裹火的小臂），但施法者的手不变成冰刃、冰锥这类实体。
4. **人在空中移动。** 俯冲、旋转上升、掠过云顶、翻到对方头顶；不原地推手。

**攻防组：**

| 组合 | 写法 | 实测出处 |
|---|---|---|
| 拨开就回 | A 双掌连拍；B 单手一拨开一掌，反手就是一记火掌回敬 | 追逐B 3–6 秒 |
| 让掌顶膝 | 侧身让开火掌，同时抬膝顶向他 | 追逐B |
| 压膝切颈 | 往下一按压住膝盖，顺势一掌切向他脖子，对方低头躲过 | 追逐B |
| 扣腕甩出 | 一把扣住对方出掌的手腕，借俯冲的力道身子一转把他整个人甩出去，袖口冻上一圈霜 | 追逐B 6–7 秒 |
| 反手接掌扫腿 | 不回头，反手接住背后打来的一掌，同时回身扫腿 | 追逐C |
| 翻顶压掌 | 翻到对方头顶，双掌聚光往下压；对方一掌迎上，火星炸开，把他震飞 | 2E（粗剪 S14–S15） |
| 旋身扫腿 | 旋身横扫一腿，腿上拖一道冰蓝光痕，对方裹火的小臂硬接 | 2E（粗剪 S12） |
| 按臂冻霜 | 贴身一掌按住对方格挡的小臂，霜从掌下顺着袖子一路往上冻，把臂上的火压灭 | 3D（粗剪 S22–S24） |
| 火臂格开 | 冲过去一掌，对方抬起裹火的小臂格开 | 2D（粗剪 S09） |

**写在长镜里：** 缠斗最适合放进一个穿越机或 360 环绕的长镜（见 `运镜与衔接.md` 第六节），一段里三四组攻防为限，写多了模型只做出一部分。每组写成一个分句，谁出、谁接、接的同时打了什么。

> 同镜连续，一刀不切：两人贴身缠斗，一边打一边在天上急速移动。双方都在进攻：A 双掌连拍，B 单手一拨开一掌，反手就是一记火掌回敬；A 侧身让开火掌，同时抬膝顶向他；B 往下一按压住膝盖，顺势一掌切向他脖子，A 低头躲过。两人边打边往下俯冲，从云顶上方一掠而过，带起的风在云海上划出一道长沟。结束时：A 一把扣住 B 出掌的手腕。

## 十二、强弱不对等怎么打（实测）

很多仙侠打戏不是势均力敌：一方在陪玩，被逼到某一刻才认真。实测场就是这样，用户反复强调两点：**强者也要格挡，弱者必须够强**，强者的强要靠弱者来衬。

| | 强者 | 弱者 |
|---|---|---|
| 出手 | 动作小、走直线、打完就定住 | 走弧线，袖子连绵不断 |
| 挡招 | 单手接，身上有法术把招接住，挡完余火还在；另一只手负在背后，只写一两刀 | 一直在战斗状态；觉得招没威力也要防一手，不能从容 |
| 脸 | 神情平静，眼神一沉，不笑 | 咬紧牙，嘴角向下 |

「一只手一直负在背后」写死整条，强者就会站着不动（实测追逐第一版）。

**强者的情绪要分级上升，每升一级配一个反应镜头：**

1. 陪玩：垂眼看对手，嘴唇闭着，冷哼。
2. 第一次被威胁：被近身冻住手臂，眉头第一次轻轻一紧，嘴唇抿住，然后第一次全身爆发，把对手冲飞（3D）。
3. 看到对方大招：有一点紧张，「这家伙动真格了」。
4. 亮底牌：化身、动真格，一口气结束战斗。

弱者第一次真正威胁到强者的那一下要拍清楚：接触点特写、强者低头看被冻住的手臂、弱者双掌推到底，再接强者爆发。

## 十三、缩地成寸（实测）

瞬移是远距离那一层的打法（贴身用拳脚，稍远用法术，再远用缩地成寸）。

- **起点**：人一闪不见，原地留下一团带招牌色的残影，散成霜点或火星。
- **终点**：先迸一圈光点，人再冒出来。
- **同时瞬移对撞**：两人同时消失，画面正中撞出白核，镜头急推冲向白核。
- **瞬移躲招**：招从残影里穿过，把残影绞散，扑了个空；人已经出现在更远、更高的地方。
- **连闪连撞**：一个时间段里写三刀快切，每刀在天上不同的位置撞一下。人很小，可能只看到两团光。
- 实测：模型有时直接跳切、不画残影，也能看懂；「化成一团冰雾」「一闪不见」都出过。

## 十四、表情和带伤（实测）

**表情：**

| 要的 | 写法 |
|---|---|
| 轻蔑 | 垂眼往下看，下巴微抬，嘴唇闭着，嘴角平直，轻轻冷哼 |
| 强者认真起来 | 眉头第一次轻轻一紧，嘴唇抿住，神情认真起来 |
| 被打中后不笑 | 愣一瞬，神情平静，眼神认真起来 |
| 硬顶 | 咬紧牙，嘴角向下，额角有汗，双臂在发抖 |
| 察觉危险 | 眼神往脚下一瞟，察觉不对，立刻往上急冲 |

不写挑眉、轻蔑地笑、嘴角勾起。表情返修时只改一点，用户原话「千万不要调整过度」。脸上不写霜、不写泪。

**带伤：**

- 血和人身上着火可能被平台判黑屏失败（实测），写轻：「颧骨上一道细细的红痕」「拇指擦过红痕」「纱袍被燎焦一块，冒几点火星」「嘴角渗出一丝红」。
- 重伤的动作分步写：身子一震 → 轻咳 → 嘴角一丝红 → 按住伤处 → 抬头。少了「一震、轻咳」，下一刀嘴角有血就没来由。
- **伤要拍到来源。** 实测第 8 条缺了冰碴划过脸的那一下，下一刀脸上就多了伤，看不懂伤是怎么来的。伤的来源单独给一刀。
- 伤的位置写清是人物自己的左右：「他自己的右肩」「他自己的左脸」。

## 十五、不要用的小动作（实测）

| 不要 | 为什么 | 换成 |
|---|---|---|
| 打响指召法术 | 太装，也看不出火星射出 | 单手掐诀、翻手，指尖弹出火星 |
| 勾手挑衅 | 用户不要 | 瞥一眼，两手负在背后 |
| 双指夹刃 | 画成一根手指点着刃，也不好看 | 侧身让开，或袖子一卷 |
| 施法者的手变成冰刃、冰锥 | 灵力是虚的，手变成实体就乱了 | 掌上只有光雾和霜点；冰刃只能放出去飞，不拿在手里贴身打 |
